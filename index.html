04 / QUESTIONS

Good to know.

Short answers for common setup questions.

01Why does a tool ask me to select something?

Tools use current AE context. Select a layer for effects and Flicker, a property for Bounce, Wiggle, Cycle, or Ping-Pong, and a composition for subtitles or project utilities.

02Can I edit what AU Toolkit creates?

Yes. Effects, expressions, keyframes, Slider Controls, nulls, and text layers remain native After Effects objects.

03Where does Code Runner save data?

User data under JakeInMotion/CodeRunner. Metadata uses Code_Runner_Data.json; larger source files use the code folder.

04What does Trim Path Follower need?

Select exactly one Shape Layer containing Path 1 and a Trim Paths modifier. Enable Rotation if the new “Trim End Follower” null should follow the path direction.

05What does Organize Project change?

Root-level footage moves into extension folders. Video, vector, and audio receive named groups; image folders can be nested under Images, and compositions under Pre-comps. Undo restores recorded moves.
